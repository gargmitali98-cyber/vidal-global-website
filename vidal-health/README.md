# Vidal Health

Next.js + TypeScript + Tailwind refactor of the imported Vidal Health HTML website.

## Structure

- `app/` — Next.js pages
- `components/` — reusable layout, homepage, product and UI components
- `content/` — all copy and product data
- `styles/` — Tailwind global styles, tokens and interactions
- `public/` — asset folders for logos, images, icons and illustrations

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
